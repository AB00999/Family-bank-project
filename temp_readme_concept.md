## 🚀 How to View

### Online
Visit: [https://ab00999.github.io/family-bank-concept/](https://ab00999.github.io/family-bank-concept/)

### Locally
1. Clone the repository
   ```bash
   git clone https://github.com/AB00999/family-bank-concept.git
   cd family-bank-concept
   ```

2. Open in browser
   ```bash
   # Windows
   start index.html
   
   # macOS
   open index.html
   
   # Linux
   xdg-open index.html
   ```

3. Or use a local server
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Then visit: http://localhost:8000
   ```
